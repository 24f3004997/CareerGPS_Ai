# Career Guidance Engine

> From Skill-Gap to Job-Fit — Powered by AI

## 🏆 Achievement

🥉 **Rank 3 — NIT Allahabad**

An AI-powered career guidance platform designed to help students identify skill gaps, build personalized learning roadmaps, improve resumes, and prepare for relevant career opportunities.

## 🚀 What It Does

- 🎯 AI Skill-Gap Analysis
- 🗺️ Personalized Learning Roadmap
- 💼 Job & Role Matching
- 📄 Resume / ATS Analysis
- 🎤 AI Interview Preparation

## 🔄 Product Flow

Resume / Profile
↓
Skill & Role Analysis
↓
Skill-Gap Detection
↓
Personalized Roadmap
↓
Job Matching
↓
Interview Preparation

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Python, FastAPI / Flask
- **Database:** Firebase / MongoDB
- **AI:** LLM-powered NLP & recommendation systems

## 🎯 Goal

Help students understand **where they are, what skills they are missing, and what they should do next** to become job-ready.

## 🏆 Recognition

Developed as a student-led AI career guidance project and awarded **Rank 3 at NIT Allahabad**.
